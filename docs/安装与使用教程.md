## 一、应用概述

PTW Command Center 是 PTW 2.0（Programming To Win 2.0）力量举新手计划的训练指挥中心。替代传统 Excel 表格，自动计算每次训练的加重幅度、判断卡壳退阶、管理轻重日循环。

**在线地址：** `https://lelucermaire31.github.io/ptw-command-center/`

**技术特性：**
- 单 HTML 文件，无需安装 App，浏览器即用
- 数据存手机/电脑浏览器本地（LocalStorage），不上传服务器
- PWA 支持，可添加到主屏幕，离线使用
- 移动端优先，适配手机屏幕
- 导入/导出 JSON 备份，跨设备迁移数据

**训练计划覆盖：**
- Phase 1（纯新手）：每周 3 天恒定训练
- Phase 2（进阶新手）：H-L-H 轻重日循环
- Phase 3（中级）：预留接口

## 二、Android 手机安装（推荐）

### 方式一：在线版（最简单，需要首次联网）

1. 手机浏览器打开：`https://lelucermaire31.github.io/ptw-command-center/`
2. 页面自动加载后，点击浏览器菜单（右上角 ⋮）
3. 选择 **"添加到主屏幕"** 或 **"安装应用"**
4. 确认安装

完成后手机桌面出现 PTW 图标，点击即全屏运行。首次安装需联网加载资源，之后完全离线可用。

### 方式二：本地 HTTP 服务器（无需外网，适合无网络环境）

电脑终端执行：
```bash
npx serve -p 3333 -s .
```

手机连同一 WiFi，浏览器打开 `http://<电脑IP>:3333`，按方式一步骤添加到主屏幕。

### 离线使用说明

PWA 安装后 Service Worker 缓存全站资源（React + Tailwind CSS + 应用本体）。断网照常打开、训练、录入——数据始终存手机 LocalStorage。

## 三、Windows 电脑安装

### 方式一：在线版（推荐）

浏览器打开 `https://lelucermaire31.github.io/ptw-command-center/` 即用。

**PWA 安装：** 地址栏右侧点安装图标（⊞↓），或 Chrome 菜单 → 应用 → 安装此站点作为应用。桌面生成独立窗口快捷方式。

### 方式二：本地文件

双击 `Exercise-Coach.html` 直接用浏览器打开。唯缺点是 `file://` 协议下 Service Worker 不工作，无离线缓存（日常使用完全 OK）。

### 方式三：本地 HTTP 服务器

```bash
npx serve -p 3333 -s .
```
浏览器打开 `http://localhost:3333`，完整 PWA + 离线缓存。

## 四、双端数据迁移（导入/导出）

应用内置 JSON 备份导入/导出，用于手机↔电脑数据迁移和定期备份。

### 导出（备份）

1. 底部 Tab → **设置**
2. 数据管理区域 → 点击 **"导出数据"**
3. 浏览器自动下载 `ptw-backup-YYYY-MM-DD.json`

文件内容：
```json
{
  "lifts": { "squat": {...}, "bench": {...}, "deadlift": {...} },
  "history": [ /* 全部训练日志 */ ],
  "meta": { "onboardingComplete": true },
  "exportDate": "2026-05-13T..."
}
```

### 导入（恢复/迁移）

1. 底部 Tab → **设置**
2. 数据管理区域 → 点击 **"导入数据"**
3. 选择之前的 `.json` 备份文件
4. 弹出确认框，显示备份概要（三项重量、日志条数、导出日期）
5. 确认后覆盖当前数据，页面自动刷新

### 典型场景

| 场景 | 操作 |
|------|------|
| 手机→电脑 | 手机导出 → 微信/邮件传文件 → 电脑导入 |
| 电脑→手机 | 电脑导出 → 微信/邮件传文件 → 手机下载后导入 |
| 定期备份 | 每次训练后导出保存到云盘 |
| 换手机 | 旧手机导出 → 新手机导入 |

## 五、首次使用：Onboarding

首次打开进入引导流程，依次录入三项数据。

### 5.1 录入起始重量

输入**深蹲、卧推、硬拉**最近一次成功完成 3-6 次的训练重量（kg）。

### 5.2 阶段选择参考

| 条件 | 选择 |
|------|------|
| 刚接触力量训练 | Phase 1 |
| 深蹲 < 1.5 倍体重 | Phase 1 |
| Phase 1 期间出现卡壳（有组 < 3 次） | Phase 2 |
| 已有线性加重训练经验 | Phase 2 |

### 5.3 完成

三个动作录入后点击"开始训练"进入主界面。数据自动保存。后续可在 Settings 中修改。

## 六、Dashboard 仪表盘

首页展示三项动作状态卡片。

### 6.1 卡片字段

| 字段 | 含义 |
|------|------|
| **Phase 徽章** | 当前阶段（P1 / P2 / P3） |
| **重量** | 上次训练重量（kg），.0/.5 尾数 |
| **目标次数** | 下次训练需达到的最低总次数（动态） |
| **训练次数** | 当前阶段已完成训练次数 |

### 6.2 targetMinReps 说明

targetMinReps 是**动态目标**，可能高于初始下限（sets×3）：

- 上次落在 Min 区间 → 不加重，targetMinReps +1 或 +2
- 正常加重后 → targetMinReps 重置为 sets×3
- 安全上限：sets×6（每组最多 6 次），不会无限增长

## 七、Session 训练课表

点击底部 **训练** Tab 进入当天训练计划。

### 7.1 课表类型

| 课表 | 阶段 | 内容 |
|------|------|------|
| 恒定日 (P1) | Phase 1 | 每次相同：深蹲 2 组 / 卧推 3 组 / 硬拉 1 组 |
| 重日 (Heavy) | Phase 2 | 高容量：深蹲 3 / 卧推 5 / 硬拉 2 |
| 轻日 (Light) | Phase 2 | 恢复日：停顿深蹲 2 / 停顿卧推 2，无硬拉 |

P2 循环模式：**H → L → H → H → L → H → ...**

### 7.2 热身计算

每个动作自动生成 4 组热身（重量取整到 0.5kg）：

| 百分比 | 次数 | 说明 |
|--------|------|------|
| 50% | 8 | 空杆/轻量激活 |
| 70% | 5 | 中等过渡 |
| 80% | 3 | 接近工作重量 |
| 90% | 2 | 神经适应 |

### 7.3 正式组录入

切换到"录入数据"标签：

1. 重量输入框默认填入上次训练重量，可改
2. 每组录入**次数**（必填）和 **RPE**（可选，仅记录）
3. RPE 输入后显示颜色标签：绿/蓝 (7-8.5) → 黄/橙 (9) → 红 (9.5-10)

### 7.4 提交训练

点击"完成训练"后自动：
1. 计算总次数
2. 判定区间（missed / min / mid / maxed）
3. 检查是否卡壳（任一组 < 3 次）
4. 计算下次训练重量 + 目标次数
5. 写入训练日志

### 7.5 Light Day 注意事项

- 仅做停顿深蹲 + 停顿卧推（各 2 组），不练硬拉
- **重量不变，不触发加重/卡壳**
- 目的：技术打磨 + 主动恢复

## 八、Log 训练日志

底部 **日志** Tab 查看历史训练记录，按日期倒序排列。

### 8.1 列表与详情

每条日志显示：日期、课表类型、各动作总次数、区间判定、卡壳标记。

点击条目展开看每组详情（重量 × 次数 × RPE）、总次数汇总。

### 8.2 编辑日志

展开后点"编辑"：可修改每组次数、RPE、重量。保存后数据更新。**注意：编辑历史不会触发算法重新计算。**

### 8.3 删除日志

展开后点"删除" → 确认 → 永久删除。

## 九、Settings 设置

底部 **设置** Tab，包含参数调整和数据管理。

### 9.1 参数调整

每动作独立修改：训练重量、阶段（P1/P2/P3）、阶段训练次数、目标最低次数。

### 9.2 数据管理

| 功能 | 说明 |

## 十、训练算法详解

### 10.1 次数区间判定（4 级）

| 区间 | 条件 | 后果 |
|------|------|------|
| **missed** | totalReps < targetMinReps | 不加重，目标不变，再挑战一次 |
| **min** | totalReps == targetMinReps | 续重，targetMinReps +1 或 +2 |
| **mid** | targetMinReps < totalReps < maxReps | 按矩阵加重 |
| **maxed** | totalReps >= maxReps | 最大加重幅度 |

### 10.2 上下肢独立加重矩阵

**下肢 (Squat / Deadlift)：**

| 阶段 | Min | Mid | Maxed |
|------|-----|-----|-------|
| P1 | +0 kg, target+1 | +2.5 kg | +5.0 kg |
| P2 | +0 kg, target+1 | +1.0 kg | +2.5 kg |

**上肢 (Bench)：**

| 阶段 | Min | Mid | Maxed |
|------|-----|-----|-------|
| P1 | +0 kg, target+1 | +1.0 kg | +2.5 kg |
| P2 | +0 kg, target+1 | +0 kg, target+2 | +1.0 kg |

### 10.3 双重递增法

核心：**Min 区间不加重，改为提升 targetMinReps。** 连续踩 Min 说明重量刚好，先提次数再提重量。

### 10.4 即时熔断（Stall）

触发：**任一组次数 < 3**

效果：
- 重量降 10%（floor 0.5kg）
- 阶段 +1
- sessionCount 归零
- targetMinReps 重置

不积累失败次数——一次触发立即执行。

### 10.5 杠铃片限制

所有重量 floor 到 0.5kg 步进，确保可用 1.0 / 2.5 / 3.5 / 5.0 kg 片实际配重。

## 十一、常见问题

### Q1：重量为什么自动变 .0/.5 结尾？

杠铃片限制机制自动取整，给出可实际配重的值。

### Q2：没加重但目标次数提高了？

落在 Min 区间。双重递增法先提高次数要求，突破 Min 进入 Mid 后才真正加重。

### Q3：卡壳直接掉 10%？

对。PTW 2.0 哲学：宁减重调整，不死磕受伤。果断退阶换阶段重新积累。

### Q4：换手机数据怎么迁移？

Settings → 导出数据 → 把 JSON 文件传到新手机 → 新手机 Settings → 导入数据。

### Q5：离线能用吗？

能。PWA 安装后 Service Worker 缓存全部资源，完全断网也能训练录入。数据存本机 LocalStorage。

### Q6：在线版数据安全吗？

数据只在用户自己浏览器里，不上传任何服务器。GitHub Pages 纯粹托管 HTML 文件，不收集任何信息。

### Q7：能不能打包 APK？

可以。项目预留 Capacitor 接口：

```bash
npm install @capacitor/core @capacitor/cli
npx cap init "PTW Command Center" "com.ptw.commandcenter"
npx cap add android
cp Exercise-Coach.html www/
npx cap sync && npx cap open android
```

Android Studio 中 Build → Build APK。

### Q8：怎么更新到最新版本？

在线版：打开 `https://lelucermaire31.github.io/ptw-command-center/` 自动获取最新版本。本地数据不受影响。

本地文件：下载最新 `Exercise-Coach.html` 替换旧文件。
