# PTW Training Command Center — Design Spec

## Context

个人 PTW 2.0 (Powerlifting To Win) 训练指挥中心。React + Tailwind CSS CDN 单 HTML 文件 PWA 应用，数据存 LocalStorage，预留 Capacitor 接口以便日后打包 APK。

## Requirements Summary

基于 `ptw-plan.txt` (PTW 2.0 原版) + `fix.txt` + `fix_2.txt`:
- 两阶段新手计划，每动作独立追踪，上下肢分离加重矩阵
- "双重递增法": Min 区间维持重量、提高 targetMinReps；Mid/Max 加重
- 杠铃片限制: 1.0 / 2.5 / 3.5 / 5.0 kg, 重量强制 .0/.5 尾数
- P1: 恒定日 (每周 3 天相同内容)，P2: 轻重日 (H-L-H 循环)
- 即时熔断: 任一组 < 3 次 → -10% (floor to 0.5kg) + 阶段跃迁
- P1/P2 算法完全隔离 RPE (UI 可填但引擎忽略)
- 训练日志完整记录，可编辑可删除
- PWA 离线 + 添加到主屏幕

## Architecture

### Tech Stack
- React 18 + ReactDOM (CDN: unpkg)
- Tailwind CSS 3 (CDN: cdn.tailwindcss.com, `tailwind.config = {}` 内联配置主题色)
- Babel standalone (CDN: @babel/standalone, JSX 转译)
- 单 HTML 文件，零构建工具
- LocalStorage 数据持久化
- Service Worker (内联注册，缓存 CSS/JS CDN + 自身)

### Module Map

```

├── App — 全局状态容器 + Tab 路由
```

## Data Model

### LIFT_CONFIG
```js
{
  squat:    { type: "lower", p1Sets: 2, p2HeavySets: 3, p2LightSets: 2, p2LightVariant: "pause" },
  bench:    { type: "upper", p1Sets: 3, p2HeavySets: 5, p2LightSets: 2, p2LightVariant: "pause" },
  deadlift: { type: "lower", p1Sets: 1, p2HeavySets: 2, p2LightSets: 0 },  // 0 = no light
}
```

### Lift State (per lift, persisted)
```js
{
  id: "squat",              // "squat" | "bench" | "deadlift"
  phase: 1,                 // 1=Novice P1 | 2=Advanced Novice P2 | 3=Graduated/Intermediate
  currentWeight: 87.5,      // kg, 上次训练重量 (.0/.5 尾数)
  targetMinReps: 6,         // 下次训练目标最低总次数 (默认 = sets×3)
  e1rm: null,               // number | null, phase≥3 才有值
  sessionCount: 0,          // 当前 phase 内训练次数 (1-indexed, 用于 P2 轻重日)
}
```

### Training Log Entry (array, persisted)
```js
{
  id: "1716xxxx",
  date: "2026-05-11T18:00:00",
  sessionType: "heavy",              // "P1" | "heavy" | "light" | "intermediate"
  squat: {
    sets: [{ weight: 87.5, reps: 5, rpe: 8.5 }],
    totalReps: 13,
    tier: "mid",
    stalled: false,
  },
  bench: { ... },
}
```

### Meta (persisted)
```js
{
  onboardingComplete: true,
}
```

## Algorithm Engine

### 1. 训练模板

**Phase 1 (恒定日)** — 每次完全相同:
```
Squat (lower):    2 sets × 3-6 reps → 下限=6,  上限=12
Bench (upper):    3 sets × 3-6 reps → 下限=9,  上限=18
Deadlift (lower): 1 set  × 3-6 reps → 下限=3,  上限=6
```

**Phase 2 (轻重日, sessionCount % 3 == 2 → Light)**:
```
Heavy:
  Squat (lower):    3 sets × 3-6 reps → 下限=9,  上限=18
  Bench (upper):    5 sets × 3-6 reps → 下限=15, 上限=30
  Deadlift (lower): 2 sets × 3-6 reps → 下限=6,  上限=12

Light (仅 Pause Squat + Pause Bench, 无 Deadlift):
  3-sec Pause Squat: 2 sets × 3-6 reps
  3-sec Pause Bench: 2 sets × 3-6 reps

Light day: 重量不变, 不触发 progression/stall
```

### 2. 次数区间判定
```
INPUT:  totalReps, targetMinReps (动态目标), maxReps (上限 = sets×6)
OUTPUT: "missed" | "min" | "mid" | "maxed"

totalReps < targetMinReps                 → "missed"  // 未达动态目标，但单组未<3
totalReps == targetMinReps                → "min"     // 刚好踩线
targetMinReps < totalReps < maxReps       → "mid"     // 超额完成
totalReps >= maxReps                      → "maxed"   // 拉满上限
```

### 3. 上下肢独立加重矩阵

**关键原则: "双重递增法"** — Min 区间不加重, 改为提高 targetMinReps。

```
下肢 (Lower: Squat, Deadlift)
┌────────┬──────────────────────┬────────────┬────────────┐
│ Phase  │ Min (总次数=下限)     │ Mid        │ Maxed      │
├────────┼──────────────────────┼────────────┼────────────┤
│ P1     │ 维持原重              │ +2.5 kg    │ +5.0 kg    │
│        │ targetMinReps += 1   │            │            │
├────────┼──────────────────────┼────────────┼────────────┤
│ P2     │ 维持原重              │ +1.0 kg    │ +2.5 kg    │
│        │ targetMinReps += 1   │            │            │
└────────┴──────────────────────┴────────────┴────────────┘

上肢 (Upper: Bench)
┌────────┬──────────────────────┬──────────────────────────┬────────────┐
│ Phase  │ Min (总次数=下限)     │ Mid                      │ Maxed      │
├────────┼──────────────────────┼──────────────────────────┼────────────┤
│ P1     │ 维持原重              │ +1.0 kg                  │ +2.5 kg    │
│        │ targetMinReps += 1   │                          │            │
├────────┼──────────────────────┼──────────────────────────┼────────────┤
│ P2     │ 维持原重              │ 维持原重                  │ +1.0 kg    │
│        │ targetMinReps += 1   │ targetMinReps += 2       │            │
└────────┴──────────────────────┴──────────────────────────┴────────────┘
```

### 4. Progression 计算
```
INPUT:  phase, totalReps, currentWeight, targetMinReps, liftType, sets
OUTPUT: { newWeight, newTargetMinReps, stalled }

若 任意一组 reps < 3:
  stalled = true
  newWeight = roundToAvailableWeight(currentWeight × 0.90)
  newTargetMinReps = sets × 3  // 重置
  触发 phase transition

否则:
  stalled = false
  tier = getRepTier(totalReps, targetMinReps, sets×6)  // 注意: 用动态 targetMinReps, 非绝对下限

  if (tier === "missed") {
    // 未达动态目标: 不加重, 目标不变, 给一次再挑战机会
    newWeight = currentWeight
    newTargetMinReps = targetMinReps
  } else {
    查加重矩阵 → {weightDelta, targetMinRepsDelta}

    newWeight = currentWeight + weightDelta
    newTargetMinReps = (weightDelta == 0)
      ? targetMinReps + targetMinRepsDelta   // Min/Mid 双重递增
      : sets × 3                             // 加重后重置 targetMinReps
  }

  newTargetMinReps = Math.min(newTargetMinReps, sets × 6)  // 上限锁: 不超过绝对最高次数
```

### 5. 重量取整
```
roundToAvailableWeight(weight):
  return Math.floor(weight * 2) / 2   // floor to nearest 0.5kg
```

### 6. Phase Transition (boolean 即时)
```
INPUT:  lift
OUTPUT: lift (mutated)

lift.phase = min(lift.phase + 1, 3)
lift.sessionCount = 0
lift.targetMinReps = sets×3  (按新 phase 的组数)
lift.currentWeight = roundToAvailableWeight(lift.currentWeight × 0.90)
```

### 7. P3 / Intermediate (RPE-based)
```
e1RM = weight / RPE_TABLE[reps-1][rpe-7]
nextWeight = roundToAvailableWeight(e1RM × 0.89)
```

### 8. Warmup Calculator
```
INPUT:  topWeight
OUTPUT: [{pct:50, weight, reps:8}, {70,5}, {80,3}, {90,2}]

weight = roundToAvailableWeight(topWeight × pct)
```

### 9. Session Scheduling
```
P1: sessionType = "P1", 全部三动作
P2: sessionCount % 3 == 2 → sessionType = "light"
    否则 → sessionType = "heavy"
```

## UI Design

### Style: Hybrid Minimal + Data-Dense
- 深色渐变 Header (slate-900→slate-800)
- 浅色内容区 (white/slate-50)
- 双列网格数据面板
- RPE 颜色 (仅展示): 7-8 绿/蓝 → 9 黄/橙 → 9.5-10 红

### Layout: 4-Tab Bottom Navigation
1. **Dashboard** — 三动作卡片: Phase, currentWeight, targetMinReps, sessionCount
2. **Session** — 当天课表 + 热身 + 录入 (标注当天 targetMinReps 目标)
3. **Log** — 历史 + 详情 + 编辑/删除
4. **Settings** — 参数 + 重做 Onboarding

### Responsive
- `max-w-lg mx-auto` 移动优先, 桌面居中 448px
- Tab bar fixed bottom + safe-area-inset-bottom
- min-h 44px touch targets

```html
  const swBlob = new Blob([`
    const CACHE = 'ptw-v1';

    self.addEventListener('install', e => e.waitUntil(
      caches.open(CACHE).then(c => c.addAll(URLS))
```

## User Preferences Confirmed

| 维度 | 决策 |
|------|------|
| 起始重量 | 直接录入为"上次训练重量" |

| UI 风格 | Hybrid: Dark header + Light body + 双列 |

## Verification

1. 算法 — P1 Lower: Min→target+1 同重, Mid→+2.5, Maxed→+5.0, 任一组<3→-10%+P2
2. 算法 — P1 Upper: Min→target+1 同重, Mid→+1.0, Maxed→+2.5
3. 算法 — P2 Lower: Min→target+1 同重, Mid→+1.0, Maxed→+2.5, <3→-10%+P3
4. 算法 — P2 Upper: Min→target+1 同重, Mid→target+2 同重, Maxed→+1.0
5. 取整 — 所有重量 floor to 0.5kg: 89.7→89.5, 90×0.9=81→81.0
6. targetMinReps — 未加重后下次目标提高, 加重后重置为 sets×3
7. PWA + 离线 + 持久化 + RPE 颜色 + 编辑删除 + Responsive
8. targetMinReps 上限锁 — P2 Upper Mid 连续触发不超 sets×6 (如 5组上限30次)
9. missed 判定 — targetMinReps=17, totalReps=16 → "missed", 不加重, 目标不变
